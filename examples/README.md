# Core examples

Start with the [physical roof and conditioned-basement notebook](roofs_and_basements.ipynb)
to inspect a cold-attic shell, internal ceiling, ground boundaries, declared
basement controls and snapshot roundtrip. It needs no network, weather or engine.
Its inputs are explicitly illustrative.

The small Python examples cover [physical authoring](physical_building.py),
[atomic assignment](atomic_assignment.py), [shared walls](shared_walls.py),
[geometry preparation](preparation_safeguards.py) and
[operating profiles](profile_resolution.py). Examples accepting weather or an
output directory document those prerequisites in their command-line help.

The [larger learning catalogue](../demo/README.md) provides independent notebooks
for geometry, weather, construction, operation and real EnergyPlus execution.
